Synthetic separate-audio HLS: testsrc2 video-only TS track + 440Hz sine audio-only TS track.
Video: H264 High level 1.2, yuv420p, 320x180, 24fps, closed 48-frame GOP, 2 B-frames; 4 x 2s MPEG-TS segments (8s total).
Audio: AAC-LC 48kHz 96kbit/s mono; 5 MPEG-TS segments (8.001333s total, last is one 21.333ms frame).
Two independent ffmpeg encodes from the same 8s window; TS timelines start 1.4833s (video) and 1.400s (audio), i.e. 83ms apart.
Generator recipe (developer-only encoder; serving and Android execution never invoke ffmpeg):
  ffmpeg -f lavfi -i 'testsrc2=size=320x180:rate=24' -t 8 -map 0:v:0 \
    -c:v libx264 -preset veryfast -profile:v high -level:v 1.2 -pix_fmt yuv420p -crf 23 \
    -g 48 -keyint_min 48 -sc_threshold 0 -bf 2 -flags +cgop -force_key_frames 'expr:gte(t,n_forced*2)' \
    -an -f hls -hls_time 2 -hls_list_size 0 -hls_playlist_type vod -hls_segment_type mpegts \
    -hls_flags independent_segments -start_number 0 -hls_segment_filename 'video-%03d.ts' video.m3u8
  ffmpeg -f lavfi -i 'sine=frequency=440:sample_rate=48000' -t 8 \
    -vn -c:a aac -b:a 96000 -ar 48000 -ac 1 \
    -f hls -hls_time 2 -hls_list_size 0 -hls_playlist_type vod -hls_segment_type mpegts \
    -hls_flags independent_segments -start_number 0 -hls_segment_filename 'audio-%03d.ts' audio.m3u8
