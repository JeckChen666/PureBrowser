# v0.1.2 候选实现与验收

日期：2026-10-02（Asia/Shanghai）。候选身份：**0.1.2-rc.3 / versionCode=7**。
最新公开发行仍为 v0.1.1。**尚未满足 v0.1.2 全部发布门槛，不创建 v0.1.2 tag，不发布正式 v0.1.2 Release。**

## 已实现

- 独立、有限的 HLS 清单解析：结束点播、master/media、相对地址、签名保留、档位选择、排除加密/直播/fMP4/BYTERANGE/独立音轨/不连续时间轴。
- 每个清单/分片/跳转都由受控 HttpTransport/RequestPolicy 执行，Cookie 按目标即时读取；跨源请求不能取得来源网站会话；无 Cookie/Authorization 持久化。
- 同一 TaskId、schema v4 原子备份迁移、2 任务 / 每任务 2 分片、有限重试、取消、Wi-Fi 等待及进程终止对账。
- MPEG-TS → Media3 采样提取 → 普通独立 MP4；单节目/单 H.264 + AAC 轨道清点、节目表 CRC、参数变化拒绝、共同时间基准、正确最后采样提交。
- 下载/封装/校验/公共发布状态分离。全部分片到齐不是成功；公共文件完成后入库一次。沿用播放、分享、忘记记录和确认删除。
- HLS 确认页显式解析/准备档位，无周期自动请求；Wi-Fi-only 预览守约，切换选项/关闭窗口取消，旧回调不得更新新草稿。
- 官方 Media3 extractor/muxer 1.11.1 及必要传递依赖；无新 DI、播放器框架、下载 SDK、FFmpeg 运行时或云业务。

## 已有证据与边界

证据保存在 `app/build/reports/v0.1.2/`（不把设备私有数据、测试 APK、第三方影片或密钥发布）。最终附件的 VERSION/SHA/证书/提交以 delivery.json 为准。

- 90 项 JUnit 单元测试通过（含 33 项有界清单解析）。
- RC3 API37：142 项完整回归通过，显式启用浏览、产品、服务、队列与真实 HLS 页面流程，无跳过；短样本精确192帧，PAT CRC、双音轨和参数变化拒绝均通过。
- RC3 API28：54 项 HLS/直链/公共文件/迁移通过；RUNNING/MUXING/PUBLISHING 强停后恢复对账各通过。API37 还验证真正的 MediaStore pending 行清理。
- API36 最终下载协调器 15 分钟锁屏：901007 ms，729/901 个分片，69183680 B，仍在下载。之后仅封装器修复和版本/测试更新；这是模拟器下载阶段证据，不是全部 OEM/长片后台保证。
- 正式签名包曾在真实 HTTPS Unified Streaming 环境完成 Tears of Steel（Blender Foundation，CC BY 3.0），184 片 / 734 秒；许可证依据与样本研究见 HLS-FIXTURES.md。RC3 正式包已在 API36 再跑通过，证据 rc3-signed-real-https.txt。相同影片不同档位不计为多个视频。
- v0.1.1→RC1→RC2 同包同签名升级保留书签、主题、Wi-Fi 偏好和真实已保存文件；RC3 继续使用同一长期证书。原 `com.example.purebrowser` 不覆盖、不跨包迁移。
- 自制 1801 秒、901 片、有立体声音频样本曾完成保存、开中尾解码与实际跨 UID 分享。外部播放发现的问题修正后，RC3 已重新跑过1801秒样本：开中尾解码及独立UID实际读取同SHA-256的MP4，见 rc3-long-share.txt。长片人工声画同步巡视仍未完成。

## 本轮发现与修复

1. 取消/完成/排队启动、等待 Wi-Fi/旧工作线程清理的状态竞态：事务内条件转换、同 ID 单工作线程、延后已授权唤醒、禁止工作线程未退出时删除/忘记。
2. 成功提交后进程死亡遗留大临时文件：冷启动只清理成功任务私有副本，保留公共成品。
3. JSON 数字窄化溢出及 BigInteger.longValueExact 的 API31 限制：精确有界解码，使用低版本可用的 BigDecimal 精确转换；API28 重跑通过。
4. HTTPS→HTTP 回环跳转：即使 Debug 也不允许 HTTPS 降级。
5. 初版独立接收器 1MiB 内存上限导致长片分享假阴性：改为有界 256MiB 流式 SHA-256；不增加媒体权限，不进入 Release。
6. 外部播放器发现 AUD/SPS/PPS-only 单元被当作画面采样，以及尾帧提交不完整：按 AUD/切片识别模式选择、过滤非画面单元、通过受控 PES 结束提交保留全部帧。短片精确 192 帧验证、主机完整解码，不以“轨道可读取”替代播放验收。
7. 回退历史缓存页面的 Resource Timing 误过滤：以文档 timeOrigin 区分新/恢复文档与同文档SPA更新，既恢复当前文档线索又保留SPA旧资源过滤；浏览/同源frame/服务实测通过。
8. 页面标题增强和媒体证据变化使老产品测试的文件名/数量断言过期：改用明确媒体来源和 URL；导航失败测试使用刚释放的设备端端口，避免与新 HLS 测试站点端口冲突。

## 未满足的发布门槛

- **3 个独立真实 HTTPS 环境 / 6 个不同获授权 HLS 视频尚未建立，当前只有一个独立影片/环境得到可复核实测。** 不拿镜像域名、多个清晰度或本地 HTTP 伪装满足。
- RC3 已有完整集中回归、长片三点解码/分享与短片逐帧/全解码证据；30分钟样本的人工声画同步/外部播放器开中尾巡视尚未完整记录。自动检查不是任意文件安全保证。
- 未做广泛真机/OEM、省电、30分钟真实内容视听验收；没有暂停、断点续传、直播、任何加密 HLS、DASH 或任意转码。
- 所有片段 URL 有冻结快照和有效期，失败后重新下载，不续传，不偷偷换档位。

## 固定限制

清单2MiB、32档位、10000片、24小时声明时长；计划文件4MiB；单片128MiB、累计接收8GiB（含重试）；单个采样16MiB、每轨最多100万采样。仅188字节 MPEG-TS 单节目、固定 PID/编码参数，拒绝多音轨/未知附加编码。预留256MiB余量，封装与公共复制分别检查剩余空间。超限不是可用性承诺。
