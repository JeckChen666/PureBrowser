## 3. 能力层次与支持合同

### A. 通用发现（L1）：自动验证补齐响应可见性

- 候选不再停留在 URL 猜测：进入**限额自动探测队列**——单次 `Range: bytes=0-1` 请求同时回答可下载性（206/200/403）、精确大小、断点支持与 Content-Type（HLS/DASH/直链分流），判容器时才拉 64KiB 前缀；预算／并发／生命周期沿用 v0.1.5 探测框架并按 D1 放宽为限额自动＋用户开关。
- 探测请求镜像页面会话（Referer/UA/Cookie）——这是大量 CDN 403 的通用解；会话资格仍受 §3-D 访问合同约束。
- **ServiceWorker 补漏**：注册 `ServiceWorkerClient.shouldInterceptRequest`（API 24+）作为第二观测点，覆盖 SW 分发的 manifest；Android 11 已知兼容问题列入回归。
- Android `shouldInterceptRequest` 不回调 blob、拿不到响应头的平台限制继续如实披露；透传代理方案本版不引入。

### B. 通用解析与下载（L4）：检出即解析、档位前移

- 检出 m3u8 后经 ~150ms 去抖批量 inspection 自动解析主清单，**变体/分辨率直接呈现在资源面板**（复用现有 `HlsPlaylistParser`）；epoch 代次防串页沿用。
- 现有 codec／字幕轨门禁从"拒绝"降级为**警告可选**（先解 TED 全 7 档位被拒的欠账，H03）；独立音轨仍按现有双轨能力评估，不虚标。
- **DASH 受限子集进入本版**：先展示（Media3 `DashManifestParser` 复用评估 → Representation 档位入面板），后下载（m4s 分片＋合并路线在 T66 内显式决策，No-go 则明确标注"仅展示"）。
- 加密 HLS（AES-128）、直播、BYTERANGE/MAP 等继续排除，UI 显式说明。

### C. 页面侧观测（L2/L3）：只读注入与播放器指纹

- 注入脚本限定**只读上报**（D2 白名单逐钩子评审）：`fetch`/`XMLHttpRequest` 上报 URL；`MediaSource.addSourceBuffer` 记录 mimeType；**Blob 构造器代理**捕获内存态 m3u8；跨域 iframe 至少记录 src。不读取／外传请求正文之外的页面数据，不改变页面语义。
- **页内配置扫描**：MEDIA_SCAN 扩展通用正则（URL + 邻近 quality/height 字段对）与播放器配置模式（`mediaDefinitions`/`setVideo*` 类 setter、`__NEXT_DATA__` 等）。
- **播放器指纹**：按播放器家族而非单站匹配——页面存在 `flashvars`/`kvsplayer`/`html5player`/`xplayerSettings`/`stream_data` 等全局变量即套用对应配置提取（挖 m3u8|mp4 URL + quality 对）。这是 tube 站长尾（含 S-A/S-B 所属家族）的通用钥匙，指纹判定实现为纯函数并配正反例测试。
- 扩展名分类采用调研沉淀的六类事实表（视频/音频/图片/压缩/文档/安装包）作为常量落地。

### D. 会话与访问合同（L4）

- 嗅探记录统一携带完整上下文字段集：`url, pageUrl, pageTitle, mimeType, quality, userAgent, referer, cookie, totalBytes, resumable, detectedAt, sniffLayer`；解析与下载阶段**逐跳回放该上下文**，经 `RequestPolicy` 的 HTTPS/host/凭据/重定向检查。
- 会话资格沿用 v0.1.1 以来合同：用户合法登录产生的 Cookie 仅用于同源媒体请求；不引入按站点的凭据截获清单；匿名站点不跨源带 Cookie。
- 悬浮下载按钮（可选增强，非阻断）：按调研模式三要点实现（挂 `video.parentElement`、`getBoundingClientRect` 换算、MutationObserver 重绑＋按元素去重）。

### 支持与排除

| 场景 | 定位 | 限制 |
| --- | --- | --- |
| 原有公开直链／限定 HLS 点播 | 必须保持 | 旧成品、任务、恢复及浏览链路不回归 |
| 无扩展名/动态媒体/SW 分发清单/页内配置型播放器（含 S-A/S-B 家族） | 通用核心新增 | 必须以真实新增成品验证；线索≠可保存 |
| DASH（mpd） | 本版受限评估 | 先展示后下载；下载路线 T66 决策，No-go 显式标注 |
| HLS 附属字幕声明 | 降级为警告可选 | H03 欠账；独立音轨仍按双轨能力实判 |
| YouTube 公开匿名点播 | H02 关口延续 | 端到端 Go 先行；No-go 显式决策，不降目标追认 |
| DRM/付费墙/验证码绕过、云解析、直播/批量、转码/4K | 不做 | 沿用 v0.1.5 边界 |
| MSE buffer 导出、按站凭据截获 | 不做 | 记录缺口，后续独立规划 |

## 4. 技术选型与依赖（T61 冻结）

- **Media3**：优先评估复用 `DashManifestParser`（及 HLS 侧解析器）；`DownloadManager` 的离线缓存格式≠mp4 成品，引入下载器需另验导出路径，不默认采用。
- **探测网络**：OkHttp 自建（现有 `HlsHttpClient`/`MediaProbe` 框架扩展），不引入新下载框架；FileDownloader／移动端 FFmpeg 系依赖一律不引入（调研结论：前者停更、后者许可与维护双风险）。
- 无云解析、无远程规则热更新、无未经决策的 GPL 路线；Apache-2.0 根许可不变。
