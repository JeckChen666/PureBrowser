## 3. P1B：一次解析，两个单变量对照

真实 Android 测试使用固定 `youtubei.js18.1.0`、同一个 Sintel／同一次匿名解析／同一视频轨／相同策略头；只改变范围终点或载体。格式160，视频声明4,865,643字节；音轨140只记录声明，不在这条诊断请求。原始地址、token、响应正文不进报告。

| 语义 | 实测结果 | 可以得出的结论 |
| --- | --- | --- |
| `Range: bytes=0-4865642` | 解析后27ms发出；HTTP403；无重定向；未读body | 当前完整 header-range 访问被拒绝。声明到期仍剩21600秒，本轮证据不支持简单归因于「等待太久／声明已到期」；并未排除解析／访问条件等其他原因 |
| `Range: bytes=0-63` | HTTP206；Content-Range0–63／4865643；实际读取64字节、ftyp可见 | 同地址能取得MP4前缀，**不是完整保存** |
| query `range=0-63`，无Range header | HTTP200；Content-Length64；无Content-Range；诊断未读取body | 载体改变后响应形态不同；严格诊断不把缺少范围总长的200回应当作完整资源或已验证可下载方案 |

元数据解析8.306秒，整条诊断10.750秒；实际3个媒体请求、64字节body观测，小于192字节预算；到非访问合同差异后停止，不重试。该真实诊断**1项失败／0通过**，失败原批次保留，不被10项夹具的绿灯覆盖。

固定库常规下载会附加同会话 `cpn` 并采用 query-range；当前 worker 只序列化 decipher 地址，没有附加该 `cpn`。这是已观察到的实现差异，**尚不是403根因证明**；不增加外部token／Cookie，也不据此更换项目许可。
