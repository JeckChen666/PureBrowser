## 1. 版本定位：站点规则层 ＋ YouTube 会话路线 ＋ 欠账清偿

> **在 v0.1.6 通用分层的基础上补上"兜底那条腿"：参考竞品实现的内置站点规则层；同时完成 YouTube 会话上下文路线（B）的有界验证，并清偿 v0.1.6 登记的增强级验收欠账。**

三条主线：

1. **站点规则层（新能力主线）**：参考闭源竞品逆向分析的规则链路（本地资料 `docs/research/video-sniffer-re/`，按红线修订可直接采纳），落地为**内置规则数据文件＋受控解释器**——匹配（页面/请求正则）→ 动作（DOM 选择器提取、播放器配置提取、清单发现提示）。按新政策：实现可照竞品模式，正式文档写"参考闭源竞品逆向分析"、不出现应用名称；规则数据内置随版本发布，**不做运行时远程下发、不做按站凭据截获**（维持 2026-10-04 修订边界）。
2. **YouTube 会话上下文路线（B，用户已定向）**：有界可行性实验先行——在同一模拟器上以"用户登录 YouTube 后的 WebView 会话"重跑 T67 电池形态，验证会话态是否解除字节窗口门控；**Go 才整合**，整合形态为显式用户开关（"使用网站登录会话"）＋红线修订记录；No-go 则维持诚实失败并把证据入档。
3. **增强级欠账清偿**：E1–E7 中与发行安全直接相关的四项（长样本封装、≥15 分钟真实后台、API28/36 矩阵、code13→v016 真实覆盖升级）在本版补测；其余（完整配对语料、无障碍全量、多厂商真机）继续登记。

成功口径：仍是**三率分报、以真实新增可用成品结账**。新增成品优先来自规则层覆盖的站点（旧失败→新成功），通用层与 S-A/S-B 零倒退。

## 3. 能力层次与支持合同

### A. 站点规则层（`media/rules/*`，建议落点）

- **规则即数据**：内置版本化规则文件（JSON，随 APK 分发、随版本更新）；单条规则＝匹配（页面 URL/请求 URL 正则，含 hosts 与 pathname 两面，参照调研报告 §5.1 的双面规则表）＋动作序列（`dom_extract`：选择器→属性/文本提取为候选；`player_config`：复用 T64 指纹提取；`manifest_hint`：把匹配请求提升为高置信清单候选）＋元数据（规则版本、负例说明）。
- **受控解释器**：规则动作在**枚举白名单**内执行（无任意 JS、无凭据读取、无网络）；解释器输出统一进 `ResourceSniffer.observe`（新证据类型 `RULE`，排序介于 DOM 与 REQUEST 之间）；规则解析失败/超时有界降级（跳过该规则，不影响通用层）。
- **规则内容**（T73 首批）：从本地资料规则模式 clean-room 转写，剔除两类：需凭据截获的条目（红线）、与通用层重复收益的条目；每条规则配正反例夹具。敏感站点域名照实入规则数据（这是"支持哪些站"的正常信息，与"竞品不指名"是两回事）。
- **入口**："分析当前视频"扩展为 规则命中即出现（与现有适配器并列）；规则命中在 UI 标注来源（"站点规则"）。

### B. YouTube 会话路线（B）

- T74 电池：登录态 WebView（模拟器人工登录一次）→ 同会话重跑分段 Range 电池（对照匿名基线）→ 结论入档。
- 若 Go（T74 后用户确认 D1）：整合为**显式开关**——默认关闭；开启后仅对 youtube/googlevideo 域使用页面会话（Cookie/UA），走既有 `WebsiteAccessContext` 逐跳校验；关闭或未登录时行为与 v0.1.6 完全一致。成品判据：一个真实 YouTube 双轨有声 MP4。
- 若 No-go：诚实失败文案维持，证据链闭环，B 路线结案。

### C. 通用层维护（不扩范围）

- 候选排序加权：引入 `declaredLength`/变体数/证据源/时长（可从清单 EXTINF 累计获得）的轻量打分，正片优先于预览/广告；负例（加权后 S-A/S-B 结果不劣化）。
- `m3u8Content` 桥接模式（可选）：注入 JS 以页面会话 fetch 清单后经只读桥回传，作为"App 端会话请求被拒"场景的备选路径。
- DASH 下载（可选，视 v0.1.6 后续反馈决定）：mpd 分片（m4s）＋合并；不承诺，No-go 则维持"仅展示"。

### 支持与排除（沿 v0.1.6 边界，增量修订）

| 场景 | 定位 | 限制 |
| --- | --- | --- |
| 规则层覆盖站点 | 本版新增兜底 | 规则内置、无运行时下发；无凭据截获；规则失败有界降级 |
| YouTube 登录会话取流 | B 路线（D1 决策） | 显式开关、仅 YouTube 域、逐跳校验；默认关闭 |
| 按站凭据截获 / 远程规则下发 / 云解析 | 不做 | 2026-10-04 红线修订未触及；再放宽须另行决策 |
| DRM/付费墙绕过、直播、转码/4K | 不做 | 沿 v0.1.6 |

## 4. 技术选型

- 规则解释器纯 Kotlin（JVM 可测），正则走 `Regex` 白名单编译（规则文件加载时校验，防灾难回溯：模式数量/长度上限）；JSON 解析沿用手写容错风格。
- 会话电池复用 `V016YouTubeGateDiagnostic` 骨架（新增 `session=on` 形态）。
- 无新依赖；media3 复用范围与 v0.1.6 相同。
