# PureBrowser 本地隐私说明

日期：2026-10-03（Asia/Shanghai）；适用 v0.1.4；继承 v0.1.3 的受控下载与本地隐私边界。

没有自有云端、账号、解析服务、遥测、同步或自动诊断上传。联网仅用于用户选择的网页和下载资源；网站自身可能收集数据。
WebView维护当前浏览器网站会话；应用不读取其他应用会话、不从JavaScript提取私有Token。
下载记录在私有目录保存来源/资源地址（可能含敏感签名query）、来源关联、选项、阶段、字节与失败分类。
受控下载不持久化Cookie/Authorization；重定向每跳执行来源策略；Set-Cookie不写回浏览器。
私有续传检查点记录有限资源校验信息、文件摘要及完整分片证明；不进入公开发行附件。
成品保存到公共Download/PureBrowser；用户主动播放/分享通过限定本地URI授权，接收应用可读取用户选择的文件。
诊断字段白名单：应用版本、OS/API/WebView版本、报告内序号、任务枚举阶段/失败、字节。
不包含浏览历史、URL/查询、Cookie、Authorization、用户标题/文件名/任务稳定ID、媒体文件、设备序列号或密钥。
用户选择后才能通过系统分享发送诊断文本；第三方接收应用由用户决定。

清理历史不删书签；网站数据为当前WebView配置的全站范围，可能退出登录。
网站/缓存清理关闭WebViews、停止受控写入并等待退出，清理期间不接受新下载/继续。
框架旧接口部分操作只有“请求”边界，不能声称全面抹除所有IndexedDB/ServiceWorker数据或其他应用数据。
停止任务恢复缓存清理会使对应进度不可继续；公共成品、记录及活动任务不被该操作直接删除。
应用关闭系统备份/提取；不承诺卸载后保留私有历史、登录或恢复缓存。公共成品需由用户管理。

## v0.1.4 的 UI 数据边界

地址输入建议、标签搜索只使用现有本地记录，不新增联网联想或历史上传。网格／列表偏好是独立本地设置，不保存查询词、网址或网页截图。
标签预览为会话内有界内存缓存（最多12张／3MiB、每张≤320×200），只取已挂载活跃页面，不加载全部标签取图、不写磁盘、不上传、不进诊断。关闭、导航与相关隐私清理释放或失效相应预览；清历史也清预览。之后用户主动再次打开总览，可以重新捕获仍打开的网页。

公开运行截图使用明确标注的自制网页／合成状态，未采集个人登录页、私人网址或真实下载成品。图中“FIXTURE”表示测试内容，不是用户数据或实际下载证明。真实传输／文件／升级证据另记验收台账。


## v0.1.5 开发候选的媒体分析边界（2026-10-04）

以下描述已落地的开发代码，不是正式发行／YouTube保存成功声明。用户主动分析才执行匿名、有界的媒体探测或站点元信息请求；不开启全网抓包，不复制播放器全部buffer，不自动解析全部标签。页面VideoObject声明与Range／无扩展名请求只有线索含义，不因发现线索而创建任务。

YouTube解析在本机Worker进行；WebView无外网／native桥／DOM或存储权限，实际HTTPS元信息由原生有限队列发往所选网站。没有自有／第三方云解析、账号Cookie导入或外部token服务。网站仍会收到完成所选解析必需的请求、当前作品标识与网络信息，这属于用户所选网站的访问，不是应用自建遥测。

所有原生元信息请求纳入网站数据清理的排他租约，取消／清理撤销在途请求；接受结果前重新核验页面代次和隐私代次。Worker、解析结果及签名轨道地址只留在本次内存生命周期，不在诊断或私有任务存储保留。双轨schema7任务只保存哈希身份、非秘密格式／字节／时长声明，及适配器单独认可的规范公开来源页面；它不是保存整个原始query的许可。旧直链／HLS任务仍按原本地存储合同处理。

双轨中断、过期或进程重启后需要用户返回公开来源重新分析／确认，不能靠持久化Cookie或把失效字节拼接为续传。下载仍受逐跳HTTPS／凭据策略和成品检查控制；不进行DRM解密、验证码或访问控制绕过。格式与初始字节解析成功不能当作完整保存成功，当前Sintel完整请求失败仍保留为阻断证据。

## 站点规则层的数据流（v0.1.8 起，2026-10-05 随 T81 记录）

- 规则层可按规则声明发起**受控网络抓取**（https-only、目标须命中规则 host 白名单、请求/字节/时长三重预算并与自动探测共用账本）；抓取来源与用量在资源中心可见。
- 规则可声明**复用浏览器既有登录会话**（仅同注册域、默认关闭、用户逐站开启）；Cookie 不导出、不落盘、不进任务 JSON/日志/诊断导出；带会话的写操作默认关闭，开启时留审计记录。
- 本节不改变既有"无云端、无遥测、本地处理"承诺。
