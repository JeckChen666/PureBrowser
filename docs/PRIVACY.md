# PureBrowser 本地隐私说明

日期：2026-10-03（Asia/Shanghai）；适用v0.1.3候选。

没有自有云端、账号、解析服务、遥测、同步或自动诊断上传。联网仅用于用户选择的网页和下载资源；网站自身可能收集数据。
WebView维护当前浏览器网站会话；应用不读取其他应用会话、不从JavaScript提取私有Token。
下载记录在私有目录保存来源/资源地址（可能含敏感签名query）、来源关联、选项、阶段、字节与失败分类。
受控下载不持久化Cookie/Authorization；重定向每跳执行来源策略；Set-Cookie不写回浏览器。
私有续传检查点记录有限资源校验信息、文件摘要及完整分片证明；不进入公开发行附件。
成品保存到公共Download/PureBrowser；用户主动播放/分享通过限定本地URI授权，接收应用可读取用户选择的文件。
诊断字段白名单：应用版本、OS/API/WebView版本、报告内序号、任务枚举阶段/失败、字节。
不包含浏览历史、URL/查询、Cookie、Authorization、用户标题/文件名/任务稳定ID、媒体文件、设备序列号或密钥。
用户选择后才能通过系统分享发送诊断文本；第三方接收应用由用户决定。

清理历史不删书签；网站数据为当前WebView配置的全站范围，可能退出登录。
网站/缓存清理关闭WebViews、停止受控写入并等待退出，清理期间不接受新下载/继续。
框架旧接口部分操作只有“请求”边界，不能声称全面抹除所有IndexedDB/ServiceWorker数据或其他应用数据。
停止任务恢复缓存清理会使对应进度不可继续；公共成品、记录及活动任务不被该操作直接删除。
应用关闭系统备份/提取；不承诺卸载后保留私有历史、登录或恢复缓存。公共成品需由用户管理。
