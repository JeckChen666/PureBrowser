# PureBrowser v0.1.9（versionCode 18）

日期：2026-10-07。基线：v0.1.8/code17 同一长期证书覆盖升级。源码：`feat/v0.1.9`（tag `v0.1.9`）。能力设计参考开源 yt-dlp（Unlicense，行为规格转写）与闭源竞品逆向分析（不指名）。

## 本版主题：保存能力补全 ＋ yt-dlp 规则流水线

- **独立音轨 HLS（分轨自动合并）**：`#EXT-X-MEDIA` 音频 rendition 与视频档自动组双轨计划，逐分片下载→分轨转封装→无转码合并为单 MP4；修复了 MediaExtractor 大轨道重读预算的真实缺陷。实站成品 2,854,196B（公开测试语料）。
- **fMP4 分片组装 ＋ DASH 下载**：SegmentTemplate/SegmentList 解析、fMP4 完整性校验、FragmentedMp4Extractor 两趟组装；DASH 支持视频＋音频双 Representation 合并与单封装档。实站成品 42,276,491B（公开 DASH 语料）。AV1/加密/SegmentBase 如实标注不支持。
- **yt-dlp 转写流水线**：静态分析 2020 个提取器（SIMPLE 519），产出 64 条验证候选；19 站实站批量验证后 3 条新增内置规则（100% 成品通过率）；累计 20 条内置规则。转写纪律：候选须逐条验证入库、POST/JS 挑战类明确弃转、上游源码不捆绑（NOTICE 溯源）。
- **规则生态安全**：Ed25519 签名导入（内置公钥、维护者私钥外部签名、未签名降级为哈希确认）；导入档预算收紧。
- **API28 矩阵恢复 37/37**（发布路径、fMP4 组装器、双轨、独立音轨 e2e）；**AV1 探针**：仅软解（API28 无解码器），结论缓至 v0.2.0。
- 修复：`V016CrossSiteSaveSmoke` 协议分发对齐生产映射。
