# PureBrowser v0.1.6（versionCode 15）

日期：2026-10-04。基线：v0.1.4/code13 同一长期证书覆盖升级。源码：`feat/v0.1.6`（tag `v0.1.6`）。

## 本版主题：通用嗅探分层增强

- **自动验证**：候选进入限额探测队列（`Range: bytes=0-1` + Content-Type 双探，20 次/epoch、清单 6 次、8 MiB 聚合字节、15s 冷却），带页面会话镜像（同源 Cookie/Referer/UA，全脱敏不落盘）。
- **检出即解析**：m3u8 检出后 150ms 去抖自动解析主清单，资源面板直接呈现清晰度档位；编码/字幕门禁降级为“可选+告警”（v0.1.5 TED 全拒欠账解除）。
- **只读页面钩子**：XHR/fetch URL 上报、`MediaSource` mimeType、Blob 构造器代理（内存态清单）、跨域 iframe src；ServiceWorker 第二拦截点（API 24+）。
- **播放器指纹**：flashvars/KVS/html5player/xplayer/stream_data 家族配置提取（URL+quality 对），按家族覆盖长尾站点。
- **直链会话透传**（同源、显式同意）与 **DASH 档位展示**（仅展示、如实标注）。
- **闭区间分段传输**：双轨下载改为 4 MiB 闭区间顺序请求＋重组，逐块校验、预算封顶。
