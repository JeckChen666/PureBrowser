# PureBrowser v0.1.3 — 可恢复的本地下载

正式签名的小范围公开测试 **Pre-release**。版本 `0.1.3` / versionCode `10`，最低 Android 8.0（API26）。

## 本版更新

- 支持有强资源身份的直链暂停与安全续传；条件不满足时拒绝追加，避免损坏文件。
- 支持 HLS 完整分片检查点及恢复，封装中断重新封装；此前 v0.1.2 候选的 HLS 点播能力纳入本次发行。
- 下载中心及通知的暂停/继续/取消入口、网络等待、停止原因和恢复缓存反馈。
- 冷启动先对账，由用户主动恢复；schema v5 保留原始备份、旧任务和未来版本保护。
- 本地隐私分项清理、用户主动脱敏诊断、布局/大字体/键盘适配。
- 修复导航后扫描卡住、弹窗焦点与键盘交互；降低大文件的重复元数据开销。

## 已知限制

- **主要在模拟器验证，OEM 后台行为待补测**；没有多人长期试用/广泛网站兼容认证。
- 仅保存自有、开放许可或明确获授权的视频，不绕过 DRM 或访问控制。
- HLS 限未加密、已结束、MPEG-TS / H.264 + 同组 AAC；不支持直播、加密/DRM、DASH、fMP4/CMAF、BYTERANGE、独立音轨合并或不连续时间轴。
- 网站会话限受控同源条件，不支持复杂分区/跨站鉴权或 JS 私有 Token；凭据不持久化或跨源转发。
- 强停后不承诺后台继续，也不在开机后静默下载；恢复需用户主动操作。
- 纯本地，无云存储、云解析、云同步、遥测或自有后端。正式版仅 HTTPS，无测试证书或 HTTP 例外。

附件不包含测试 APK、样本视频、设备私有数据或签名密钥。
