# PureBrowser v0.2.1（versionCode 20）

日期：2026-10-07。基线：v0.2.0/code19 同一长期证书覆盖升级。源码：`feat/v0.2.1`（tag `v0.2.1`）。

## 本版主题：用户交互体验优化

- **LOGO 上线**（"下载即主角"方向）：全密度启动器＋自适应图标＋Android 13 单色层，关于页/通知/README 品牌位统一。
- **下载链路 2 步化**：点开候选 → 保存（清晰度已预选"· 默认"，准备折叠为保存进度）；换清晰度 +1 次；**长按候选 1 步快捷保存**（记忆默认：Wi-Fi/会话/命名）；规则多格式同屏选择。
- **提示语用户化**：约 195 条文案审计（改写 58/折叠 14/删除 5）；失败原因全部改为行动建议（"该视频受站点保护，暂无法保存""链接已过期，请回到视频页面重新打开"）；技术细节收进"技术详情"折叠；术语替换（清晰度/播放地址/视频文件）；脚本扫描 23 文件 0 违禁术语。
- **无障碍**：快捷保存与清晰度选择补齐 TalkBack 标签与选中态描述；修复 Wi-Fi 阻塞提示不随网络恢复刷新的缺陷。

## 实测证据

两挑战站默认路径 2 步、快捷 1 步（真机实测入档）；547 项 JVM＋75 项设备测试全绿、lint 0 错误；规则站 2 步路径因 fMP4 硬边界部分达成（走适配器 4 步，如实登记，[台账](../RELEASE-ACCEPTANCE-V0.2.1.md)）。

## 已知边界

规则站点的部分播放地址仍需走"分析当前视频"（4 步）；悬置议题（规模化补足、YouTube 会话等）按用户指示顺延。

## 安装

`purebrowser-v0.2.1.apk`（附件），SHA256 见 Release 资产说明；与 v0.1.4–v0.2.0 同证书，可直接覆盖升级。
