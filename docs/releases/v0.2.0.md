# PureBrowser v0.2.0（versionCode 19）

日期：2026-10-07。基线：v0.1.9/code18 同一长期证书覆盖升级。源码：`feat/v0.2.0`（tag `v0.2.0`）。能力设计参考开源 yt-dlp（Unlicense，行为规格转写）与闭源竞品逆向分析（不指名）。

## 本版主题：能力完整度——关闭已知死胡同

- **HLS fMP4 音视频双轨**：视频与音频 rendition 均支持 fMP4 分片（`Fmp4SegmentAssembler` 复用），`EXT-X-MAP` BYTERANGE 初始化段以精确闭区间拉取并逐项校验。实站成品 208,453,130B（DUAL_TRACK，arhiiv.err.ee）。
- **转写流水线根因修复＋规模化**：递归 AST 指针合成＋实测路径富集（23 条 live 验证）＋fetch host 受控扩展（内置档特权、导入档禁用）。12 条新规则入库（共 32 条），5 条实站成品（含 masters.tv 473MB RULE-direct）。
- **AV1 运行时门控**：三态（无解码器隐藏／软解警告／硬解可用），成品校验含解码可用性防御。
- **FFmpeg 议题结案：永不引入**——全部现存拒绝形态可由 fMP4/Media3 路径覆盖（各 1–5 天工作量），加密/直播/AV1 属产品红线 FFmpeg 无法改变。
- **QuickJS 不立项**：实测 0 站因"地址须执行站点 JS"受阻（阈值 ≥3 未达）。
- 修复：fMP4 夹具缺 ENDLIST、双轨 mux 看门狗时长、`MediaFormat.KEY_MIME` 笔误、API29 守卫。
