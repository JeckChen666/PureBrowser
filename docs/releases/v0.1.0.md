# PureBrowser v0.1.0 — 本地产品基础版 / Source Preview

发布日期：2026-10-02（Asia/Shanghai）

这是 PureBrowser 的首个开源源码预览里程碑。浏览器以网页视频发现与授权保存为核心，不提供自有云存储、云解析、云同步、账号服务器或遥测。

## 已完成

- 原生首页、地址/搜索、多标签、网页导航、书签、历史、快捷站点与主题设置。
- 当前标签的资源候选、资源中心、详情、来源与下载确认。
- 公开 MP4/WebM 等直链的实际系统下载、进度、取消、关联重试与来源恢复。
- 本地视频库、搜索排序、真实元信息/缩略图、显示标题修改、实际文件打开与临时只读授权分享。
- 移除记录与删除文件分开、文件失效展示、本地持久化与重启对账。

## 已知限制

- HLS/DASH/blob 只发现和说明，不下载分片或合并成品。
- 不支持登录态下载，不转发 Cookie/Authorization/Referer。
- 不支持手动暂停、直播、DRM、真正无痕或任意存储目录。
- 未完成真机、大文件、长时间后台和全面性能/安全验证。
- 应用身份仍为 `com.example.purebrowser`，versionName 为 `0.1.0`，versionCode 为 `2`。
