# PureBrowser v0.1.1 — 嗅探与受控直链增强

这是首个正式签名的小范围测试 APK；GitHub 标记为 Pre-release，不是全站下载器。

## 主要变化

- 活跃页自动发现动态视频和同源 iframe，播放候选优先、证据合并、多标签隔离；保留原签名地址。
- 所有新任务使用应用受控传输，不再交给系统 DownloadManager；最大 2 并发、取消、重新下载与中断对账。
- 支持 MP4/WebM 直链及无后缀可确认视频；可按明确规则使用当前网站同源 Cookie 和最小来源信息，确认页可关闭。
- 逐跳校验，凭据不跨源、不写入任务/日志；无证书绕过、云解析或任意头复制。
- 成品保存到公共 Download/PureBrowser，保留视频库、实际打开/分享、标题、来源与明确删除。
- schema v3、稳定 TaskId、旧格式备份迁移与未来版本保护；独立正式发行身份。

## 安装与升级

正式 applicationId：`io.github.jeckchen666.purebrowser`；versionName `0.1.1`、versionCode `4`；最低 Android 8.0/API26。

**不是 v0.1.0 Debug 包的覆盖升级。** 原 `com.example.purebrowser` 和 `.debug` 变体保持独立，不卸载旧应用、不自动搬运其数据或网站登录。
后续正式版本使用同包同签名升级。API26–28 需要公共目录读写权限；API33+ 通知权限可拒绝，但请在下载中心查看状态。

## 验证与已知限制

验收范围与详细证据见 `docs/V0.1.1-COMPLETION.md` 和 Release 附件的交付清单：单元/产品回归、API28 权限与文件、API36 网站条件与动态页面、实际跨 UID 分享、15 分钟限速后台、进程重启、正式签名覆盖升级及 10 个授权视频/3 个 HTTPS 托管环境。

仍无 HLS/DASH 成品、直播、DRM、复杂跨站鉴权、暂停/续传或真正无痕。部分服务会拒绝/限流/过期；网站访问成功不保证能保存。只支持有限容器初检，不承诺完整解码安全、全网站/真机/OEM/长电影后台覆盖。

无自有云端存储、解析、同步、账号或遥测；只保存自有或获授权内容。源码采用 Apache-2.0；测试 APK、私有密钥与个人数据不发布。
