# PureBrowser v0.1.8（versionCode 17）

日期：2026-10-06。基线：v0.1.7/code16 同一长期证书覆盖升级。源码：`feat/v0.1.8`（tag `v0.1.8`）。能力设计参考开源 yt-dlp（Unlicense，行为规格转写）与闭源竞品逆向分析（不指名）。

## 本版主题：规则层主动提取 ＋ 格式选择器

- **受控抓取**：规则可声明 fetch 目标（https-only、host 白名单、命名组模板、三重预算并与自动探测合并账本）；安全负例全绿（私网/IP 字面量拒绝、跨源跳转拒绝、降级拒绝、Cookie 头不可自设）。
- **会话复用（默认关闭）**：规则声明同注册域会话、确认页逐站开启、凭据不落盘不跨域、写操作 GET-only。
- **四个新动作**：jsonExtract／regexExtract／ogMeta／parseManifest（灾难正则加载期拒绝）。
- **格式选择器与画质选择 UI**：最佳／指定清晰度／指定容器；产物直填变体列表。
- **17 条内置规则＋用户导入通道**（≤512KB、同规校验、SHA-256 完整性确认、导入档预算减半、跨源跳转一律拒绝；非对称签名延后如实登记）。
- 传输侧：跨源重定向剥离同源 Cookie（不外泄）；HLS 地址片段容错；API<29 发布路径改应用专用目录（带迁移提示）。

## 实测证据

- 规则站 4/4 端到端成品：archive.org 1.1MB（直链）、Dailymotion 1.5MB（HLS 288p）、video.blender.org 22.6MB（1080 直链）、framatube.org 23.3MB（1080 直链）。
- 447 项 JVM 单测、lint 零错误；S-A/S-B 与既有规则站零倒退（[台账](../RELEASE-ACCEPTANCE-V0.1.8.md)、[规则证据](../V0.1.8-T89-RULES-EVIDENCE.md)）。
- T88：YouTube 匿名窗口实测为固定前缀（≈6.9%，无状态、不可推进），多解析拼装无效——No-go 闭环；会话路线（T74 电池）仍待人工登录后补测。

## 已知边界（诚实声明）

TED 为纯视频轨（独立音轨，产品声明边界）；Wikimedia 受上传集群 429 限流；Odysee 在本环境不可达；YouTube 完整保存维持匿名 No-go。DRM/付费墙/验证码绕过、远程规则下发不做。
