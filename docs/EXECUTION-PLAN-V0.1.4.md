## 1. 版本定位

> **统一 UI 与核心交互改版：让现有浏览、视频发现、下载和本地文件管理能力，共用一套冷灰＋蓝色、紧凑、清楚且不打扰网页的界面。**

用户打开应用后，应看到明显统一的新界面，而不是只有首页换色；从首页到浏览、标签、资源、下载、视频库和设置，不再出现两套信息密度与操作语言。

本版不以扩展下载协议或增加网站兼容数量为主线，不改浏览器内核，不重写已有受控下载、HLS、恢复或文件归属逻辑。
保留 v0.1.3 的纯本地、同包同证书升级、真实能力控制、主动恢复与隐私边界。一次工具打开、页面跳转或主题切换，不得导致活跃网页被无故重载。

### 用户可感知的五项结果

1. **浏览更清爽**：顶部地址栏、底部五个常用动作；资源和下载按需出现，不常驻挤占网页。
2. **找标签更快**：接近全屏的纵向总览，网格／列表切换、搜索与当前标签定位。
3. **发现与保存更清楚**：候选、下载方案和任务分开；临时速览与完整管理页分工明确。
4. **找回文件更顺手**：紧凑视频网格和统一文件操作面板，缺失文件、移除记录与物理删除不混淆。
5. **全局体验一致**：书签、历史、设置以及浅色／深色、键盘、系统返回和大字体采用一致规则。

## 2. 已确认方向与本计划建议

### 2.1 沿用定稿，不再发散

- 冷灰底色、蓝色强调、低装饰；统一字号、图标、间距、圆角和列表密度。
- **地址栏在顶部**，展示／编辑使用同一入口；键盘出现不把地址栏搬到底部，不产生第二输入框。
- **底部为返回、前进、首页、标签、菜单**，不使用早期底部地址栏方案。
- 标签总览为接近全屏的纵向双列网格，支持紧凑列表与搜索；定位当前只显示图标。
- 临时工具按需展开，复杂管理使用完整页面；图标优先不等于危险操作只剩图标。
- 图稿是方向参考，不照抄生成的商标、扫码符号、示例内容、固定行数或精确尺寸。

### 2.2 为实施补齐的建议规则（不是此前已确认的细节）

| 议题 | 本版建议默认规则 | 验证与边界 |
| --- | --- | --- |
| 标签默认与偏好 | 默认网格；显式切换后在本机记忆网格／列表偏好 | 不因数量变化突然切视图；偏好失败回退默认，不破坏旧数据 |
| 标签顺序 | 保持现有创建顺序，切换不自动重排；进入总览让当前标签可见 | 不引入拖拽排序或最近使用重排 |
| 搜索 | 本地匹配当前打开标签的标题和网址，忽略大小写；不混入历史／书签 | 空白恢复全部；无结果有清空入口；定位当前清除筛选并滚动定位 |
| 关闭标签 | 沿用现有规则：关非当前不换页；关当前选相邻；关最后一个生成首页 | 不增加批量关闭；撤销不列入必要范围，不承诺恢复已销毁 WebView 的页面栈 |
| 模态与专页 | 同一时刻仅一个有效工具面板；进入管理页先关闭工具，返回恢复浏览上下文 | 不把资源、确认、速览层层叠放；中断确认不创建任务 |
| 返回与键盘 | 工具内先处理其输入／内部步骤；退出工具后再处理网页后退；地址编辑先取消编辑 | 在 T41 明确状态表；没有网页后退时保留现有退出策略，不把系统返回当作关标签 |
| 地址输入建议 | 使用现有本地历史／书签提供有数量上限的建议，注明来源 | 无联网联想、无历史上传；取消还原当前地址，提交一次才导航一次 |
| 顶部展示 | 优先可辨认域名；编辑显示完整网址；刷新／停止就近放置 | 不用锁形图标承诺可信；IDN、长域名、省略和凭据部分不能造成身份误认或泄漏 |

这些默认值在实现纵切时验证；若需改变已确认的地址栏位置、页面职责或整体风格，应重新确认，不借“适配”悄悄换方案。

“覆盖”不要求生成图与实机像素一致，但不得用只改主题颜色代替页面和交互落地。

### 3.2 P1：有余量再做，不阻挡 v0.1.4

- 关闭标签的短时撤销：先明确只能恢复记录还是可恢复完整网页状态，再实现和说明。
- 更精细的面板动效、长按提示、滚动过渡；无障碍名称和焦点反馈仍为 P0。
- 首页更丰富的展示、额外筛选与个性化；不得增加未经确认的数据采集或网络请求。
- 平板专用多栏／折叠屏专用布局及更广真机体验测试；普通可变窗口下基本可用仍为 P0。

### 3.3 明确不做

DASH、直播、加密 HLS、跨站鉴权扩展、DRM 绕过、真正无痕、账号／云同步／云解析／遥测、内核替换、内置高级播放器、任意保存目录选择器、扫码、联网搜索联想、标签分组／批量管理、自动收缩地址栏及隐藏切页手势。
不默认升级 AGP、Compose 或迁移导航框架；只有必要且另有依据时再安排，不把 UI 版做成框架升级版。

## 4. 工程实施约束

### 4.1 先建立状态模型，再替换页面

T41 先明确浏览输入、临时面板、管理页和返回路径之间的互斥关系。优先收敛现有 `BrowserScreen` 的多个面板布尔状态，避免新速览再次叠加独立开关。
只做支撑本轮的必要拆分，不以 UI 改版为理由重写整个 ViewModel、路由与引擎。

- 浏览上下文保留 TabId、WebView、网页栈和阅读位置；进入管理页不新建标签。
- 资源方案继续绑定打开时冻结的来源／代次；切换标签或导航后不能把旧候选当作新页面资源。
- UI 展示观察现有任务；忙碌／不可用动作按真实能力禁用或反馈，快速连点不重复建任务。
- 现有 testTag 与语义尽量稳定；确需调整时同步修订测试，不通过删用例、放宽断言掩盖回归。

### 4.2 标签缩略图与性能纵切

标签网格需要页面预览，但不能为获取缩略图加载全部网页：

- T44 先验证仅在活跃网页合适时机截取预览；导航变化使旧图失效，不混用不同 TabId／代次。
- 仅限本机会话内、缩小尺寸、有明确预算的缓存；不持久化网页截图、不上传、不写诊断。
- 关闭标签、缓存淘汰和隐私清理时释放／失效相应预览；不能因网格／列表切换反复抓图。
- 无可用预览时展示稳定占位、标题和域名；不使用概念图或随机封面冒充真实网页。
- 覆盖 1／24／50 标签；0 标签作为异常恢复输入测试，正常最后一页关闭后保留首页。
- 若纵切发现截图导致卡顿或内存风险，先解决预算与占位策略；限制必须记录，不扩大到全量离屏渲染。

### 4.3 紧凑不压缩真实操作区域

以设计文档的颜色、14sp 正文、18–20dp 视觉图标和 4／8／12／16dp 间距为起始试验值，不作为硬编码像素合同。
有效点击目标首轮按至少 48dp 验收；危险操作保留文字和确认。必要状态不能藏在过小的元信息里。

手机优先：标签默认双列、视频库常规宽度可三列；实际按宽度与字体缩放降列，不能强行固定列数。
深色是本版必要项，不能因为定稿只有浅色图就删除原有深色能力。
横屏、低高度、分屏和较大窗口先确保全部功能可达，不承诺本版有平板专属信息架构。

### 4.4 数据与安全不变

- 不计划改下载 schema v5、TaskId、2 任务／2 分片并发、请求策略或发布流程。UI 偏好使用最小本地存储；若必须改浏览数据格式，单独补迁移测试和原数据保护。
- 下载百分比不代替封装／校验／发布；未知大小不造百分比，失败分类按真实证据。
- 暂停／继续／取消／重新下载不互换；原任务恢复不冒充新任务，另建下载不承诺续传。
- 冷启动先对账，由用户主动恢复；打开速览不能顺便启动任务。
- 移除记录保留文件，物理删除须确认；分享仍走受控 URI 授权。
- 分项隐私清理与诊断预览／主动分享保留；界面瘦身不能隐藏授权与清理范围。
