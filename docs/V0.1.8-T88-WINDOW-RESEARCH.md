# v0.1.8 T88 窗口策略研究：YouTube 匿名字节窗口精确定界与分段策略 Go/No-go

日期：2026-10-04（Asia/Shanghai）。分支 `feat/v0.1.8`。性质：T81 承接 T67 的**有界策略电池**（单次解析、硬预算 ≤16 次 media open、匿名、标准 Range 语义、无 Cookie/token/pot），目标只有一个——把匿名窗口刻画到足以对"未来分块策略"做出 Go/No-go 二选一结论。

## 实验设计

- 新增 `V016YouTubeGateDiagnostic#windowStrategyDiagnostic`（实站、显式 opt-in `video=<11字符id>`、无参空操作）。一次全新 IOS 解析（生产解析路径，19.2s，itag137/818p/clen=170,210,373B），随后对**最大 avc1 轨**执行四组有界探测，全部经共享计数传输层硬性封顶 **≤16 次 media open（含跳转）**，每臂 body 读取 ≤64KiB+1、20s 截止、生产重定向/头策略。输出仅 masked `WIN[...]` 标量行（比例 + 通过/失败 + 共享 arm JSON；无 URL、无参数值）。
- 矩阵：
  1. **边缘阶梯**：闭合 1KiB 区间（`bytes=X-X+1023`），起点取 clen 的 5/10/12/15/20/30/50%，随后在最高通过档与最低拒绝档间二分收窄至 ≤±1%（预算允许时）；
  2. **无状态性**：紧跟一次窗口外 403 之后的窗口内探测；
  3. **节流**：3 次连续窗口内探测（不同起点：5%/3%/1.5%）；
  4. **跨度敏感性**：2% 起点上闭合 1KiB/64KiB/1MiB/4MiB 四档跨度。

## 分析

1. **窗口边缘**：对 itag137 今日窗口为 clen 的**固定前缀 (6.25%, 7.50%]**（终点字节区间 [10,639,171, 12,765,777]，中点 ≈6.88%≈11.7MiB，精度 ±0.63%）。T67 的 clen/10≈10% 假设被本轮直接否证：10.00% 起点探测 403。T67 全部 34 个历史观测与该括号一致（历史上最高通过终点：137=4.93%、160=6.80%、140=7.29%，均 ≤7.5%；无任何观测超过）。
2. **跨度不敏感**：同一 2% 起点上 1KiB→4MiB 四档全 206（4MiB 档终点 4.46% 仍在窗口内）。结合 T67 的 X/Y 臂（小跨度但终点出窗 → 403），**约束变量确证为 Range 终点，不是跨度**：终点 ≤ 边缘即放行，与请求跨度无关。
3. **无状态性**：50% 档 403 之后紧邻的 5% 探测 206；整轮 7 次失败与 9 次成功交错，无惩罚/锁闭。门控按单请求形态执行，服务端不追踪本会话已取位置——**不存在可被"推进"的会话游标**。
4. **无节流**：连续窗口内成功探测延迟 564→217→55ms（含 4MiB 档 2222ms 的大 body 读），无随成功次数递增的延迟或拒绝。
5. **跨解析一致性（多解析组装的关键检验）**：T67（≥2 次独立解析、IOS/ANDROID_VR 两客户端、三条轨道、不同日期）与本轮（1 次全新解析）合计 ≥5 个不同解析产物 URL 上，窗口**始终是同一形态的 clen 前缀**（各轨边缘比例不同：约 6.25%–29% 括号，但永远 ≪100%），从未观测到任何一次"新鲜解析让更靠后的字节通过"。

## 结论（二选一）：**No-go——匿名闭区间分段无可行策略**

- **窗口刻画（本题的"策略输出"）**：匿名 googlevideo 门控 = 按轨道 URL 的 clen **固定前缀**放行（本轨今日 6.25%–7.50%，±0.63%）；终点出窗即 403，与跨度、顺序、前置失败、请求频率无关。
- **为什么没有可行策略**：完整传输的末片终点必然是 clen−1（100%），恒在窗口外；"多次重新解析＋分片重组"只有在新解析能使窗口**后移**（滑动授权）时才成立，而第 3、5 条证据（无状态 + ≥5 次解析跨天跨客户端形态不变）共同排除了滑窗模型——重新解析至多重新授予同一段前缀。在"仅匿名、无 Cookie/token/pot、标准 Range 语义"硬约束下，请求形态空间（闭合/开放/无 Range/查询参数载波）已被 T67 与本轮穷尽，全部指向同一门控。**前缀 ~7% 可以取到，其余 ~93% 取不到，故完整双轨不可达。**
- **产品含义**：v0.1.6 的闭区间分段传输（`DualTrackTransfer`）实现是正确的，对无门控 CDN 依旧有效，无需为 YouTube 改动；YouTube 双轨保持既有诚实失败（ACCESS_CONDITION）即为本研究的准确行为，非缺陷。剩余可行路线只有正交的会话上下文（T74 `sessionRangeBoundedDiagnostic` 电池已就绪，待应用内登录后带 `session=true` 执行），属另一决策，不在 T88 范围。

## 边界（严格证据约束）

- 本轮在**单次解析**内完成全部 16 探测；"重新解析不移动窗口"的判断依据是跨轮/跨天/跨客户端的一致性（T67＋本轮），未在同轮内做第二次解析（预算所限）。
- 边缘比例**逐轨不同**（160/140/137 括号互异），本轮只精确定界了 itag137 今日值；未测其他视频/码率，不外推具体百分数，只外推"前缀型、恒含头部、恒不含尾部"这一不变量。
- 403 响应体未读（0 body），错误细节不可观测，不影响状态码层面的结论。
