## 支持与限制

纯本地：无自有云存储、云解析、云同步、账号、遥测或后端。

- 支持 HTTPS MP4/WebM 直链、限定的同源 Cookie/来源条件，以及有可靠资源身份的安全续传；不能继续时明确说明，不错误追加。
- 支持未加密、已结束的 MPEG-TS / H.264 + 同组 AAC HLS；不支持直播、DRM/加密、DASH、fMP4/CMAF、BYTERANGE、独立音轨/字幕合并或不连续时间轴。
- 网站 Cookie 按适用请求即时读取，不持久化 Cookie/Authorization，不转发跨源凭据，不提取 JS 私有 Token。
- 不保证所有网站、分区/复杂跨站会话、Service Worker/MSE/跨域 iframe；不提供真正无痕。
- 用户主动恢复；不承诺进程强停后继续运行或开机静默下载。成品在公共 `Download/PureBrowser`，忘记记录不删除文件。
- **主要在模拟器验证，OEM 后台行为、真机长期压力和多人试用尚未覆盖**。可选项目不阻挡本次公开测试，不写成通过。
