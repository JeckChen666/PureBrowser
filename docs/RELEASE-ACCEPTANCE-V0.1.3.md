# v0.1.3 发行验收台账（公开预览版）

本次按用户要求调整验收层级：安全与数据完整性保持硬门槛；扩大站点、OEM 和多人试用改为可选增强。
此调整只适用于 v0.1.3 APK / GitHub Pre-release，不等于商店验收或全机型稳定性认证。
**最终版本 0.1.3 / code10；M1–M8 已具备公开预览版发行证据，T40 收尾见 [完成摘要](V0.1.3-COMPLETION.md)。**

本表替代本版原“两厂商真机、30视频/5环境、5人7日、正式中间版本顺序”的阻断要求。
v0.1.2 未发布的事实和旧验收记录保留；它的 HLS 正确性、隐私、文件与故障要求继续验证，但不再重复叠加旧样本数量门槛。
当前开发机执行方法见 [开发机验收方案](DEVELOPMENT-MACHINE-ACCEPTANCE-V0.1.3.md)。

可选指可以晚做，不指可以忽略已知缺陷。没有真机证据的发行必须明示“主要在模拟器验证，OEM后台行为待补测”，不能声称全机型稳定。
