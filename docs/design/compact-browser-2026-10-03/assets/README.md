## 生成与组合方式

- 五张分组图通过本轮配置的 `gpt-imagegen` 工具生成／编辑，请求模型名为 `gpt-image-2`；它们是 AI 生成的视觉概念，不是真实应用截图。
- 总览在本地从五张分组图裁切拼接而成，没有放大源图，不宣称原生 4K 或额外生成的细节。
- [manifest.json](manifest.json) 记录最终文件名、宽高、字节数、SHA-256，以及总览的裁切矩形和放置规则。
- 裁切坐标使用源图像素，格式为 `[left, top, right, bottom]`，右／下边界不包含在裁切结果中。总览每列对应一张分组图，图片按 1:1 像素居中放置。
- 图像生成不保证可重复得到相同结果；重新生成后应人工检查，并同步更新文字说明、总览与清单，而不是沿用旧校验值。

## 不能直接用于生产的部分

- 图中的站点、标题、封面、日期、时长、大小、进度和数量均为演示信息，不能成为功能或兼容性证据。
- 生成的 Logo、商标、字体与图标只是示意，不声明其授权或作为正式品牌素材交付。
- 正式 UI 应使用统一的组件、资源和语义；不要从 PNG 截图裁出按钮直接作为交互界面。
- 小字、触控目标、颜色对比、焦点与屏幕阅读器行为需在代码中验证；静态 PNG 无法表达这些能力。
