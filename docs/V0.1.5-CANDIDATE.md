## 实现范围

- 有界的无扩展名／脚本端点／声明 MIME／Range 请求线索，弱线索最多32，整体最多200；导航隔离和强线索优先，不记录请求认证头。
- JSON-LD VideoObject 页面媒体声明：脚本数量／文字／节点／深度有界；声明的文件保持待分析，不冒充真实 video 元素或可信网站会话。
- 用户主动的匿名媒体分析：最多64KiB，验证 Range／长度／容器，拒绝音频、分片、矛盾 MIME 和未知响应，不自动下载或转发 Cookie。
- 公共站点 resolver 接口／注册器：YouTube 及标准 PeerTube 公开元数据路径；PeerTube 不按域名白名单实现，支持 UUID 与默认 shortUUID，验证作品、公开属性和下载开启。
- 固定 MIT YouTube.js18.1.0 及 Apache/BSD/MIT/ISC 依赖；本地 Worker 无 native/DOM/storage/network 权限，原生有界 HTTPS 元数据队列受隐私请求排他控制，不采用云解析／外部 token 服务。
- 一任务双轨、H.264/AAC无转码MP4，原有队列／公共发布／归属清理；两轨签名地址只在一次内存租约，磁盘只保留非秘密身份／声明及适配器认可的公开来源。
- 原数据备份迁移、真实失败、冷启动要求重新分析；双轨**不承诺暂停／续传／直接重试**，这些操作能力为false，不拼接失效旧字节。
- 明确的codec／时戳／时长／样本／空间预算和DRM保护结构拒绝；共享起始偏移，最多一AAC帧编码预滚；既有直链／HLS路径保持。
- 统一分析、格式选择、确认和任务阶段UI；解析仅获取信息，用户确认后才传输。关于页与离线许可证文本已更新。
