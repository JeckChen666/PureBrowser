# v0.1.6 T61 冒烟取证：S-A／S-B 首次命中正文视频

日期：2026-10-04（Asia/Shanghai）。分支 `feat/v0.1.6`。执行方式：`V016CrossSiteSmoke`（androidTest，instrumentation 参数注入 URL/Cookie/超时，无 URL 参数时为空操作；输出 host 一律哈希脱敏，测试代码与本文档不含任何站点标识）。

环境：PureBrowser_API37_ReleaseLab AVD；生产装配 `BrowserSession`（完整嗅探栈，非测试桩）；每站一次运行，未播放视频（`mediaPlaybackRequiresUserGesture=true`，全程无手势）。

## 结论

| 场景 | v0.1.5 快照 | 本次 v0.1.6 分层基线 | 通过 |

| S-A 详情页 | 0 正文命中 | **4 个清晰度档位（240/480/720/1080）master 清单全量命中**，1080 档探测 VERIFIED＋变体解析（firstVarH=1080）；来源 Evidence.DOM（页内播放器配置收割→指纹解析链路） | ✅ |
